Configuration initiale (une seule fois)

Ce fichier a besoin d'une base Firebase gratuite pour synchroniser le planning entre tout le monde, sans que vos témoins aient besoin d'un compte.

  1. Allez sur console.firebase.google.com et créez un projet (gratuit, "plan Spark").
  2. Dans le projet : Build → Firestore Database → créer une base, mode "test" pour commencer.
  3. Dans Build → Authentication → Sign-in method, activez Anonyme.
  4. Dans Paramètres du projet → Vos applications, créez une appli Web, copiez l'objet firebaseConfig.
  5. Collez-le dans ce fichier à la place du bloc marqué À REMPLACER (cherchez-le tout en haut du <script>), puis enregistrez et rechargez cette page.

Ensuite, hébergez ce fichier (GitHub Pages, Netlify, ou votre hébergeur) et partagez le lien : vos témoins l'ouvrent directement, aucune connexion requise de leur côté.
